Shanghai Family Trip PWA v1.20 — Family Trip Cover

การเปิดไฟล์
1. แตก ZIP ทั้งหมดก่อนเปิด
2. index.html และโฟลเดอร์ images ต้องอยู่ข้างกัน
3. หากอัปโหลดขึ้นเว็บ ต้องอัปโหลดทุกไฟล์และรักษาโครงสร้างเดิม

แผนที่มี 2 โหมด
- ตำแหน่งครบ: ค่าเริ่มต้น แสดงหมุดและเส้นทางบนพื้นหลังในเครื่อง ไม่เกิดช่องว่างจากแผ่นภาพออนไลน์
- ถนนออนไลน์: แสดงรายละเอียดถนนจาก OpenStreetMap และต้องใช้อินเทอร์เน็ต

บนมือถือ แนะนำเปิดผ่านเว็บไซต์ HTTPS เพื่อให้ PWA และ Offline cache ทำงานครบ
